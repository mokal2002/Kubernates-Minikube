# 📦 Pods

### `kubectl apply -f my-pod.yml`

Creates and runs a Pod using yml configration file.

```bash
kubectl apply -f my-pod.yml
```
<hr>
### `kubectl describe my-ngnix-pod`

Creates desscribes pod.

```bash
kubectl describe my-ngnix-pod
```

<hr>

### `kubectl describe pod my-ngnix-pod`

 desscribes pod.

```bash
kubectl describe pod my-ngnix-pod
```

<hr>

### `kubectl delete all --all`

delete every pod

```bash
kubectl delete all --all
```
