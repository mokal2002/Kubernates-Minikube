# 📦 Manage Pods

### `kubectl run my-pod --image=nginx`

Creates and runs a Pod using the **nginx** container image.

```bash
kubectl run my-pod --image=nginx
```

---

### `kubectl get pods`

Lists all Pods in the **default namespace**.

```bash
kubectl get pods
```

---

### `kubectl get pods -n <namespace>`

Lists Pods in a specific namespace.

```bash
kubectl get pods -n <namespace>
```

Replace `<namespace>` with the namespace name.

---

### `kubectl describe pod <pod-name>`

Shows detailed information about a specific Pod, including its status, configuration, and events.

```bash
kubectl describe pod <pod-name>
```

---

### `kubectl logs <pod-name>`

Shows the logs generated by a Pod's container.

```bash
kubectl logs <pod-name>
```

Useful for checking application output and troubleshooting problems.

---

### `kubectl exec -it <pod-name> -- /bin/bash`

Opens an interactive shell inside a Pod's container.

```bash
kubectl exec -it <pod-name> -- /bin/bash
```

This works when the container image includes `/bin/bash`.

---

### `kubectl delete pod <pod-name>`

Deletes a specific Pod.

```bash
kubectl delete pod <pod-name>
```

Replace `<pod-name>` with the Pod's name.

---

### `kubectl apply -f pod.yaml`

Creates or updates a Pod using a YAML configuration file.

```bash
kubectl apply -f pod.yaml
```

The YAML file contains the Pod's configuration, such as its name and container image.

---

## 📋 Quick Reference

| Command                                    | Use                      |
| ------------------------------------------ | ------------------------ |
| `kubectl run my-pod --image=nginx`         | Create a Pod             |
| `kubectl get pods`                         | List Pods                |
| `kubectl get pods -n <namespace>`          | List Pods in a namespace |
| `kubectl describe pod <pod-name>`          | Show Pod details         |
| `kubectl logs <pod-name>`                  | View Pod logs            |
| `kubectl exec -it <pod-name> -- /bin/bash` | Open shell inside Pod    |
| `kubectl delete pod <pod-name>`            | Delete a Pod             |
| `kubectl apply -f pod.yaml`                | Create/update from YAML  |
